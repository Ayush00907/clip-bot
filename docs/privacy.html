Privacy Policy

Last updated: 19 November 2026

clip-bot is a personal tool used only by its owner to upload videos to the owner's own YouTube channel.

What data it uses

With the owner's permission, clip-bot uses Google OAuth to access the owner's YouTube account in order to upload videos and read public video information (titles, licenses, view counts) through the YouTube Data API. It does not access, collect or store data from any other user.

How data is stored

The OAuth token is stored only as an encrypted GitHub Actions secret belonging to the owner. No personal data is sold, shared with third parties, or used for advertising.

Google API Services

clip-bot's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. It uses YouTube API Services; see the YouTube Terms of Service and Google Privacy Policy.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.
